## Purpose

Oferecer um assistente de IA que, a partir do perfil do usuário, das metas ativas e do consumo já registrado, gere sugestões de dieta em linguagem natural, usando um provider externo de LLM (DeepSeek), com custo e privacidade controlados.

## ADDED Requirements

### Requirement: Solicitação de sugestão de dieta
The system SHALL let an authenticated user request a diet suggestion by supplying a free-text intent (for example "sugerir o que comer no jantar" or "montar 1 dia dentro da minha meta") and MUST reply with a natural-language suggestion in Portuguese generated by the configured LLM provider.

#### Scenario: Sugestão gerada com sucesso
- **WHEN** um usuário autenticado envia uma solicitação de sugestão com um intent válido e o provider externo responde com sucesso
- **THEN** o sistema retorna o texto da sugestão junto com um identificador da interação para auditoria

#### Scenario: Intent vazio
- **WHEN** o usuário envia uma solicitação sem intent ou apenas com espaços em branco
- **THEN** o sistema rejeita a solicitação com uma mensagem indicando que um intent é obrigatório

### Requirement: Contexto do usuário no prompt
The system SHALL include, in every request sent to the LLM provider, a structured context containing at minimum the user's active daily targets, the summary of today's consumo so far, and the user's goal (perder / manter / ganhar peso), and MUST NOT include the user's e-mail, password, session token, or any other user's data.

#### Scenario: Contexto mínimo obrigatório
- **WHEN** o sistema monta o prompt para o provider
- **THEN** o payload inclui as metas ativas, o consumido do dia e o objetivo do usuário, e passa por uma verificação que garante que nenhum dado de outro usuário está presente

#### Scenario: Perfil incompleto
- **WHEN** o usuário solicita sugestão sem perfil completo e sem metas
- **THEN** o sistema recusa a chamada com uma mensagem orientando a completar o perfil antes de usar o assistente, e NÃO invoca o provider externo

### Requirement: Configuração segura do provider
The system SHALL read the DeepSeek API key from a server-side configuration source and MUST NOT expose it to the frontend, to logs, or to any response body.

#### Scenario: Chave ausente
- **WHEN** o serviço é iniciado sem a chave configurada
- **THEN** as chamadas ao endpoint de sugestão respondem com um erro de configuração e uma mensagem apropriada, sem tentar chamar o provider

#### Scenario: Chave nunca aparece em logs
- **WHEN** o sistema emite logs relacionados a uma chamada ao provider
- **THEN** o valor da chave é omitido ou mascarado nos registros

### Requirement: Controle de custo e taxa
The system SHALL enforce a per-user rate limit of at most 20 diet-suggestion requests per hour and MUST enforce a maximum output length configured for the provider, rejecting further requests within the window with a clear "limite atingido" response.

#### Scenario: Dentro do limite
- **WHEN** um usuário faz até 20 requisições em uma janela de uma hora
- **THEN** o sistema as processa normalmente

#### Scenario: Limite excedido
- **WHEN** o usuário tenta uma 21ª requisição dentro da mesma janela de uma hora
- **THEN** o sistema rejeita com status de "muitas requisições" e informa quando ele poderá tentar novamente

### Requirement: Auditoria de interações
The system SHALL persist, for every completed diet-suggestion request, an audit entry containing the user ID, the timestamp, the intent, a redacted copy of the contexto enviado (sem segredos), the resposta do provider e o custo estimado em tokens quando disponível.

#### Scenario: Registro após sucesso
- **WHEN** uma sugestão é gerada com sucesso
- **THEN** uma entrada de auditoria é gravada e pode ser consultada pelo próprio usuário através do histórico de interações

#### Scenario: Registro após falha do provider
- **WHEN** o provider retorna erro
- **THEN** uma entrada de auditoria é gravada indicando a falha e o motivo, sem armazenar a chave da API

### Requirement: Disclaimer de escopo
The system SHALL include, together with every generated suggestion, a disclaimer stating that the content is informativo, não substitui aconselhamento profissional e não constitui prescrição clínica.

#### Scenario: Disclaimer presente
- **WHEN** o sistema retorna uma sugestão de dieta ao usuário
- **THEN** a resposta contém o texto de disclaimer acordado, em português
